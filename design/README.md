# Design – Alpaka Test

Statický export z plátna https://claude.ai/artifact/JwcqcGRp7pgBGdsndFk8Du
Jde o vizuální předlohu, ne o kód aplikace (pevné rozměry, inline styly, ukázková data,

Mobil 390×844, web 1280×800. Soubory otevřeš dvojklikem v prohlížeči.
